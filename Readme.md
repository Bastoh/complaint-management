Here's how we would be working with the repo 
Firstly pull the main branch i.e. (git pull origin main) to keep it up to date (main -> main)
Then before you commence with your task you create a branch (git checkout -b  branch name)
Then after you're done with your work you add, commit and push to your created branch 

Example of what I mean 
git checkout main
git pull origin main
git checkout -b backend/notifications
Start work 
After work 
Add, commit and push to backend/notifications
